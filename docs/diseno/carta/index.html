Floor 13 · Cartas de mago

Maqueta de la carta: cuatro atributos, cinco estados (Bronce, Plata, Oro, Neón y carta en blanco). Cada carta se dibuja desde datos: el nivel y el color salen de las cuatro notas del examen. Los nombres son inventados.

Cómo se genera

  • Datos → carta. El nivel es 0,30·TÉC + 0,30·PRE + 0,25·CRE + 0,15·ENS y el tramo (Bronce, Plata, Oro, Neón) se calcula solo. Para cambiar un dato basta con editar MAGOS en este archivo.
  • Texto real. Nombre, notas y etiquetas son texto, no imagen: siempre se leen y se actualizan al subir de nivel.
  • Marco y datos por código. Escudo, iconos y cifras son vectores (SVG), sin fondo recargado para que todo se lea. El retrato es un hueco de foto: ahí irá la foto real del mago.
  • Para compartir como PNG (más adelante): renderizar la misma carta en el servidor y guardarla como imagen.
